## 1. Status Definitions

| Status | Definition |
| :--- | :--- |
| **VERIFIED** | Implemented, integrated, exercised end-to-end, and supported by automated reproducible tests. |
| **PARTIAL** | Core functionality implemented and verified, but certain secondary extensions or options remain deferred. |
| **REGRESSED** | Previously working behaviour broken or altered undesirably. |
| **MISSING** | Required specification is completely absent from the codebase. |
| **BLOCKED_EXTERNAL** | Functionality requires genuine external clinical sign-off, model approval, annotation, or licensing. |

| **UNVERIFIED** | Evidence is insufficient to establish clinical or empirical validity. |
| **NOT_APPLICABLE** | Explicitly excluded or superseded by AUB with justification. |
