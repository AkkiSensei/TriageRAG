1. **Engineering Foundation (100% Green):**
   - All static analysis, strict typing (190 files), architectural boundary linting, clinical data validation, and golden test suites pass with **Exit Code 0**.
   - **521 automated test suites pass cleanly**, with exactly **1 expected failure (`xfail`)** intentionally preserved under Human Decision Gate **HD-6** (gross overdose ceiling multiplier requiring dual clinical sign-off).

2. **Conditions Governing Academic Demonstration:**
   - **Condition 1 (Synthetic Ground Truth):** The benchmark dataset (224 cases) and retrieval corpus (65 protocols, 617 chunks) are 100% synthetic. The 100-case blinded human annotation protocol (T4.2) remains blocked pending external clinician annotation (**HD-7**).

   - **Condition 3 (Deterministic Mock Drafting):** Plan drafting is powered by the deterministic offline mock generator (`FakeLLM`), properly identified via UI badges (`MOCK`). Deep neural embedders (T7.2) and live neural LLM providers (T7.7) are implemented as typed boundary interfaces, with live execution strictly blocked under **HD-10** and **HD-14**.
   - **Condition 4 (Candidate Rule Isolation):** All 49 candidate clinical rules (40 curated in Batches 1–3, 9 auto-mined from openFDA) carry `verified: false` and are badged `UNSOURCED DRAFT` in demo mode, while strictly failing closed in strict mode (**HD-7**).

### Scientific Conclusions:
1. **Predicate Scoring Value:** Calibrated predicate scoring provides a statistically significant improvement over pure lexical BM25 (+10.0 pts Recall@1, +0.0800 MRR, paired CI `[+0.0267, +0.1500]` strictly excludes zero) and completely eliminates false acceptances on ambiguous vitals (FAR drops from 0.1935 to 0.0000).
2. **Contextual Chunking:** While `contextual_predicate` achieves a +0.0533 point estimate gain in MRR, its 95% bootstrap CI `[-0.0067, +0.1200]` crosses zero. In accordance with strict statistical adoption gates, it is retained as an experimental arm and **not** promoted to production default.
3. **Calibration Refusal (HD-12):** Conformal and isotonic probability calibration are refused by code (`CalibrationDataRefusalError`). Ground-truth human annotations do not yet exist; labeling retrieval confidence as calibrated clinical probabilities is scientifically forbidden.

## H. Security & Operational Assessment

1. **Authentication Boundary:**
   - Implemented via constant-time token comparison (`secrets.compare_digest`) in `src/triagerag/api/security.py`.
   - Supports `Authorization: Bearer <token>` and `X-API-Key: <token>`.
   - Exempts documentation and health endpoints (`/api/health`, `/docs`, `/openapi.json`). Protected triage and eval routes return 401 Unauthorized when credentials are missing or invalid.
   - **Deployment Disclosure:** Clearly documented as an academic research prototype authentication boundary, not enterprise RBAC/SSO.
2. **Rate Limiting:**
   - In-memory sliding-window algorithm tracks client request timestamps.
   - Rejects excess requests with `HTTP 429 Too Many Requests` and supplies mandatory `Retry-After: <seconds>` response header.
3. **Dependency Vulnerability Audits:**
   - Command: `python tools/tasks.py security-audit`.
   - Python (`pip-audit`): Tooling hook integrated; optional local execution.
   - Web (`npm audit`): Inspected `web/package-lock.json`. Identifies 26 vulnerabilities across development dependencies (`esbuild`, `vitest`, `tinypool`, `openapi-typescript`). All flagged packages are dev-time testing/bundling tools, not exposed in production web client code.
4. **Untrusted Input Isolation (Rule R7):**
   - Untrusted chief complaint strings (`chief_complaint_untrusted`) are strictly excluded from engine rules, vector retrieval queries, and LLM drafting instructions by default.
   - Zero raw HTML rendering (`dangerouslySetInnerHTML` and Streamlit `unsafe_allow_html` strictly forbidden).
5. **Secret Inspection:**
   - Zero secrets or API keys checked into repository. Only `.env.example` is tracked.
